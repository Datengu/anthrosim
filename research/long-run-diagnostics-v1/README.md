# Long-run diagnostics v1 assets

This directory contains the example study protocol for the #220 long-run regime diagnostic contract.

The example values are illustrative only. A real study must justify and freeze its metric set, convergence tolerances, window sizes, cycle periods, run-length endpoints, analysis-window alternatives, and initialization/environment grouping coordinates before interpreting long-run results.

Normative semantics are documented in `docs/research/long-run-regime-diagnostics-v1.md`.
