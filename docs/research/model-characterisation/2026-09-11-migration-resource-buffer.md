# Exploratory model-characterisation: local migration as a resource-scarcity buffer

**Date:** 2026-09-11  
**Status:** exploratory complete  
**Evidence role:** model characterisation only  
**Model target:** AnthroSim `0.3.6`, `anthrosim-model-semantics-v37`  
**Executable source commit:** `9f0914e2772cd2f0c6243ab4be8b296f3ce48f30`  
**Empirical claim status:** none

## Question

Under AnthroSim's current synthetic resource and permanent-migration assumptions, does allowing bounded local household migration buffer long-term demographic contraction under resource pressure, despite migration itself carrying costs?

This is a question about the behaviour of the model. It is not a claim about any real prehistoric population.

## Why this question was suitable

The experiment exercises already-implemented M3 resource/condition/mortality mechanisms together with M4 permanent household migration. It deliberately avoids site-specific archaeological interpretation while the framework remains within its audit/readiness gate.

## Design

The same general synthetic setup was run with permanent migration enabled and disabled.

| Setting | Value |
|---|---:|
| Founder population | 2,000 |
| World | 64 × 64 cells |
| Duration | 100 years |
| Household size | 5 |
| Migration radius | 3 cells when migration enabled |
| Annual food need | 100 synthetic units/person/year |
| Seasonality scale | 1000 permille |
| Productivity scale | 500, 750, 1000 permille |
| Permanent migration | enabled / disabled |
| Replication | 30 matched seeds per condition |
| Total runs | 180 |

Matching the same seeds between migration-enabled and migration-disabled conditions makes the comparison more informative than comparing unrelated random samples.

## Main result

Mean living population after 100 years:

| Productivity scale | Migration enabled | Migration disabled | Mean paired difference |
|---:|---:|---:|---:|
| 500 | 695.7 | 9.3 | +686.4 |
| 750 | 684.1 | 109.8 | +574.3 |
| 1000 | 684.1 | 267.9 | +416.2 |

Approximate 95% intervals reported for the matched-seed migration effect were:

- 500 productivity: `+658.7` to `+714.2`;
- 750 productivity: `+553.4` to `+595.2`;
- 1000 productivity: `+382.4` to `+450.0`.

Migration produced the larger final surviving population in all `30/30` matched seeds at each of the three tested productivity settings.

At productivity scale 500, the reported aggregate contrast also included approximately:

| Measure | Migration enabled | Migration disabled |
|---|---:|---:|
| Unmet resource units | 1,025 | 124,391 |
| Condition-mediated deaths | 8.7 | 1,408 |
| Completed household moves | 2,131 | 0 |

For moving households at that setting, the pooled mean reported origin resource score was about `435/1000`, while the reported destination resource score was about `999.8/1000`.

## Interpretation

Under this specified synthetic AnthroSim configuration, bounded local permanent migration strongly buffered demographic contraction associated with spatial resource pressure. Within the model, the benefit of relocating to locally better-supported cells outweighed the implemented travel/relocation costs across all three tested productivity regimes and every tested seed.

This does **not** establish that migration has the same magnitude of effect in a real archaeological population. The current resource quantities, information radius, movement timing, utility weights, travel-condition cost, mortality response and other numerical assumptions remain synthetic unless separately evidence-grounded.

## Why the result matters for model development

The experiment reveals that M4 migration is a very strong causal lever under the tested synthetic baseline. That means future empirical studies could be highly sensitive to assumptions about:

- how far households can inspect for alternatives;
- how often relocation opportunities occur;
- how resource information is represented;
- how much better a destination must be;
- movement cost and relocation risk;
- how condition and mortality respond to scarcity and travel.

The result therefore motivates targeted sensitivity analysis before any archaeological interpretation depends on the migration mechanism.
