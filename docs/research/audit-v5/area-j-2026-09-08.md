## Frozen-target source/design inspection

### Executed-design binding

Frozen `scripts/research-identifiability.py` explicitly wraps the statistical analyzer with an executed-design authority layer introduced after AV4-011/#535. Real-study CLI use does not trust a free-form downstream `point.parameters` table. It derives a binding from the immutable `anthrosim-research` manifest/plan pair and rejects parameter, structure or execution identities that disagree with that binding.

Frozen `scripts/research-identifiability-bind-design.py` independently reconstructs research definition identity, execution identity, exact Cartesian point order, exact coordinate values, resulting configurations, point identities and run identities. Numeric coordinate values are copied from the declared exact JSON design into the binding rather than invented downstream.

This means AV5-007 is downstream of an otherwise valid exact-coordinate binding: the precise coordinate can be preserved correctly and still lose information later when the practical-identifiability width diagnostic coerces it to binary64.

### Equifinality and compensation reporting

Frozen v0.3.5 source distinguishes:

- acceptable, unresolved, compatible and rejected regions;
- claimed parameter identification from structural identification;
- multiple compatible parameter combinations from one unique optimum;
- nuisance parameters that retain multiple compatible values;
- profiles and pairwise interaction surfaces;
- held-out corroboration from calibration evidence.

The top-level equifinality summary is driven by surviving parameter-combination multiplicity and/or structural equifinality rather than only by whether a narrower declared claim passes. This is the repaired scientific direction expected after historical AV3 nuisance-compensation/equifinality findings.
