## Fresh adversary: survivor-conditioning window alignment

Evidence-only PR #657, exact head `58f7b6bd5dd7d20330804e6091ce7b3e65c8a4ab`, introduced a frozen-target adversary for `scripts/research-survivor-conditioning.py::validate_protocol()`.

The gate already requires any comparison using `meanLivingConditionPermille` to jointly declare a recognized survival/population observable. The fresh test constructed two otherwise equivalent protocols:

1. **Matched control:** terminal-window survivor-conditioned `meanLivingConditionPermille` plus terminal-window `finalLivingPopulation`.
2. **Mismatched adversary:** terminal-window survivor-conditioned `meanLivingConditionPermille` plus an **early-window** `finalLivingPopulation`, with both observables still present in the same comparison.

Scientific oracle: an early-window population measurement cannot disclose survivor selection at a terminal survivor-conditioned endpoint, so the mismatched protocol must fail closed.

Dedicated workflow run `34187243024`, job `101937940280`, produced:

```text
matched_window_valid=True; mismatched_window_valid=True; mismatched_failures=[]
```

The evidence job then failed intentionally at the scientific oracle:

```text
AssertionError: survivor-conditioning gate accepted a terminal survivor-conditioned condition comparison whose only survival/population observable is bound to a different analysis window
```

This is a deterministic scientific-oracle failure, not an infrastructure failure. The evidence PR was closed unmerged after preservation.

## Finding AV5-008 / issue #658 — P2

`validate_protocol()` checks only that a recognized survival/population observable ID is included in the comparison. It does not require that observable's `analysisWindowId` to match the survivor-conditioned condition observable's `analysisWindowId`.

Consequently, a protocol can satisfy the survivor-conditioning safeguard while measuring survival at a different time boundary from the conditioned endpoint. That can support a misleading treatment interpretation because differential survival at the actual endpoint can remain undisclosed.

This defect affects downstream scientific-governance/analysis validation, not authoritative simulator trajectory generation. It is therefore classified **P2**.

Frozen-target applicability was checked against `v0.3.5`: the audited `scripts/research-survivor-conditioning.py` blob is `a6c2ce854d43e6168c40b13191b26d004820ba9a`. The core `StudyProtocol` validation ensures referenced windows exist but does not impose cross-observable window equality, leaving this semantic obligation to the survivor-conditioning gate.

Issue: #658 — `[Audit v5][P2][AV5-008] Survivor-conditioning gate accepts mismatched survival analysis window`.

## Other inspected Area-L surfaces

The frozen target's analysis tooling was inspected for the earlier failure classes required by the audit protocol. Existing safeguards and explicit semantics were found for the following, without a separate new finding in this pass:

- survivor-conditioned `meanLivingConditionPermille` explicitly declares the survivor estimand, conditioning, and no post-death imputation;
- recognized survival/population sources are fail-closed rather than inferred from free-form labels;
- sweep weighting distinguishes run-level aggregation from pooled row-level quantities instead of silently treating them as interchangeable;
- observable support/legacy compatibility uses explicit source identities and schema-aware validation rather than accepting arbitrary descriptive names;
- study-protocol observables bind to declared analysis-window identifiers and invalid/missing identifiers are rejected at protocol validation;
- prior fresh v5 H/J evidence already demonstrates that uncertainty/precision and identification/discrimination gates are not clean, so Area L carries those findings instead of treating the existence of summary fields as sufficient evidence of statistical validity.

No claim is made that every conceivable downstream statistic is scientifically validated. Area completion means the planned v5 Area-L surfaces received fresh falsification plus source inspection under the audit protocol, with defects preserved where demonstrated.
