## Frozen-target integrity assessment

### Exact configuration and source identity

The frozen target derives research point identity from typed expanded scientific configuration and derives exact run identity from that point plus seed and exact source identity. Exact scientific execution rejects unavailable or dirty source identity rather than substituting an ambiguous placeholder. Operational filesystem location is not part of the scientific identity, which the fresh relocation adversary independently confirmed.

### Retry, duplicate handling and crash recovery

`anthrosim-research --retry` reconciles immutable root metadata, validates existing completed child bundles before retaining them, reconstructs missing/malformed mutable state from immutable plan plus validated children, and rejects changed definitions against an existing research root. The lower-level run-directory transaction layer publishes staged replacements atomically and contains explicit recovery paths for interrupted promotion/backup states while failing closed on ambiguous remnants.

The fresh Area-K adversary exercised the higher-level combination that matters scientifically: completed-child validation plus operational relocation plus total loss of mutable orchestration state. It retained exact scientific identity and result.

### Bundle completeness and artifact immutability

Canonical run bundles are validated across experiment manifest, population/world state, checkpoint, events, metrics, spatial wrappers and optional evidence/observability artifacts before downstream acceptance. Packaging validates the bundle before producing deterministic archive contents and excludes unrelated files. The sentinel used by the fresh adversary intentionally remained outside the canonical bundle set; its survival established retention rather than scientific-artifact acceptance.

### Checkpoint and continuation identity

Frozen provenance/checkpoint contracts bind model semantics and continuation lineage while distinguishing source revision provenance from the scientific resume-compatibility boundary. Existing frozen-target checkpoint and run-bundle invariant tests remain useful controls, but were not substituted for the required fresh v5 adversary.

Provenance correctness does not rescue a statistically invalid gate decision.
