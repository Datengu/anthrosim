## Status

This document records the first completed M8 Level-D evidence-grounded spatial null-model benchmark defined in `m8-first-evidence-grounded-benchmark.md` **and** the later verification rebaseline required after the M2 demographic-time scientific repair.

The benchmark remained case-study-neutral and did not target a known settlement, route, archaeological feature, boundary or desired spatial pattern. The current machine-readable regression reference is preserved in `examples/m8-first-evidence-grounded-benchmark/reference-result.json`. Earlier exact references remain preserved in Git history and must not be treated as if they were generated by the current model semantics.

## Interpretation

The tested terrain-to-movement-cost mapping can materially alter individual trajectories. Under the current semantics-v6 benchmark, stronger terrain constraints produce a robust paired effect on total migration distance according to the predeclared criterion, but the broader spatial-structure signal remains mixed: terminal largest-cell concentration is fragile, and occupancy duration and Herfindahl concentration are not distinctive.

The defensible interpretation remains bounded:

- real-world-derived terrain can propagate through the deterministic model and measurably affect simulated outcomes;
- downstream spatial results are sensitive to upstream causal semantics such as demography;
- one robust metric in this synthetic benchmark does not validate the terrain-cost transformation as a historical human movement law;
- the overall benchmark still does not establish a robust, general spatial-concentration effect;
- a visually plausible single run remains inadequate evidence, and paired ensembles/sensitivity remain necessary.

## What this does not establish

This benchmark does not establish that:

- the simulated population represents a particular historical population;
- the selected terrain patch represents an ancient landscape state;
- the terrain-contrast proxy is a calibrated human travel-cost function;
- water, land use, vegetation, soils or resource geography are historically realistic;
- the synthetic demographic or migration rules are empirically valid for a particular society;
- a similar-looking simulated spatial pattern explains any archaeological pattern;
- terrain had no or one universal historical effect because of this null-model result.

The benchmark is Level D of the M8 validation ladder: evidence-grounded environmental constraints with reproducible ensemble sensitivity. It is not Level E case-study validation.

## Analysis correction in the original benchmark

The first execution of the original aggregation script incorrectly classified every run as degenerate because the postprocessor compared the serialized camel-case stop reason `durationReached` against the Rust-style string `duration_reached`.

Inspection of the authoritative run manifests showed that all 32 simulations had in fact reached the full configured duration. The postprocessor was corrected without changing seeds, model parameters, landscape, evidence catalogue or terrain transformations, and the complete four-arm benchmark was rerun. That corrected original observation is the historical baseline described above; it must not be confused with the later semantics-v6 rebaseline.

## Reproduction

A third party can reproduce the input package and benchmark as follows:

1. regenerate the public input package using `scripts/prepare-m8-benchmark-landscape.py` with the pinned source SHA-256;
2. require byte-identical equality with `examples/m8-first-evidence-grounded-benchmark/` input files;
3. execute four ordinary `anthrosim ensemble` commands with seeds 8601-8608 and the predeclared common settings, changing only the corresponding terrain mechanism file;
4. supply `evidence.json` so source evidence is part of immutable experiment identity;
5. run `anthrosim-spatial-observability tree` over each arm;
6. run `scripts/aggregate-m8-spatial-benchmark.py` over the four experiment roots;
7. compare the aggregate to the current machine-readable reference for the current `MODEL_SEMANTICS_ID`.

The dedicated M8.6 workflow automates these steps and now preserves the generated artifact even when an exact frozen-reference check fails, allowing a legitimate semantics change to be reviewed before deliberate rebaselining.

## M8 scientific conclusion

M8 has demonstrated the complete generic path:

```text
open external spatial evidence
    -> pinned/reproducible preprocessing
    -> normalized immutable landscape
    -> explicit sensitivity-testable model transformation
    -> deterministic spatial ensemble
    -> machine-readable spatial observability
    -> predeclared aggregate interpretation
```

The later M2 repair demonstrates an equally important property: preserved downstream benchmarks can reveal when an upstream causal correction changes scientific behavior. Those changes should be reviewed and recorded, not calibrated away.

Follow-on empirical work must still be driven by a specific research question, evidence, uncertainty and competing explanations rather than by adding generic complexity or treating this synthetic benchmark as archaeological validation.
