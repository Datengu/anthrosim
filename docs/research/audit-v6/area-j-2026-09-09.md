### Mechanism

The v35 real-study binding correctly validates:

- point identity;
- exact numeric research coordinates;
- canonical structural identity;
- exact execution-ID sets.

It does not validate the supplied `outputs` against those executions. After coordinate/identity validation succeeds, deterministic `outputEvidence` causes the supplied finite value to be consumed as exact evidence without an authoritative result resolver, content identity or deterministic derivation check.

This conflicts with the normative v0.3.6 contract, which states that `{"kind":"deterministic"}` means the output is **genuinely deterministic for the declared analysis**.

The result is a direct false-positive parameter-identification path even while `executedDesignBound=true`.

This was preserved as **AV6-012 / #737 P1 — identifiability deterministic outputs are not bound to authoritative executions**. Remediation remains deferred.

## Frozen-target source and contract inspection

### Executed-design coordinate authority is strong

The v0.3.6 front end derives real-study parameter/structure authority from the immutable `anthrosim-research` root rather than trusting downstream coordinate assertions. It independently reconstructs definition, research, point and run identities and validates row parameter coordinates, structure identity and execution IDs.

This is the repaired direction required after AV4-011/#535. AV6-012 does not bypass or contradict that repair; it demonstrates the next semantic layer that remains unbound: the output used to decide which valid executed points are compatible.

### Stochastic evidence binding remains separate

The schema distinguishes deterministic evidence from `monte_carlo` evidence. A Monte Carlo row references an immutable diagnostic identity and the analyzer checks its estimate, interval, replicate count, seed identities and precision decision before use.

Area J does not duplicate AV6-010/#729: that finding already establishes a missing semantic link one layer upstream between submitted per-seed Monte Carlo values and authoritative study outputs. AV6-012 is fully deterministic and requires no stochastic diagnostic.

### Numeric parameter-coordinate fidelity is repaired

The v0.3.6 identifiability front end preserves exact JSON integer coordinates through compatible-range arithmetic and uses exact rational width calculation before serialization. Unsafe mixed integer/float domains beyond the binary64 consecutive-integer range fail closed. This is the repaired direction expected after AV5-007/#651.

### Held-out threshold and evidence-role controls remain explicit

The wrapper rejects a negative corroboration-discrimination tolerance, preserving the AV5-006 repair. Calibration and held-out corroboration observables remain disjoint, and held-out evidence cannot silently rescue an equifinal calibration claim.

The clean #736 control additionally shows that a successful narrow parameter claim does not erase broader alternative parameter combinations or structures.
