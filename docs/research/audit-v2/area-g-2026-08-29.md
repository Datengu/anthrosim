## Initialization and path-dependence disposition

The current contracts correctly refuse to treat the synthetic founder state as a neutral prehistoric prior. `declared_founder_state_v1` can transport explicit ages, sex, household membership, residence, condition, living-parent links and pre-run reproductive timing; its remaining chronology defect is already recorded as AV2-003/#320.

Spatial founder initialization explicitly treats founder geography as causal initial-condition uncertainty. Its controlled no-relaxation regression preserves two alternative layouts for two years: the concentrated case remains four people in one cell with terminal largest-cell share 1000 permille, whereas the split case remains two people in each of two cells with terminal largest-cell share 500 permille. This is appropriate adversarial evidence that elapsed time alone is not a burn-in argument.

Initial M3 food stock is explicitly configurable and is not silently inherited from physical storage capacity. The contract requires either direct interpretation of early transients or predeclared sensitivity/convergence analysis before claiming initial-stock insensitivity.

The long-run diagnostic contract is appropriately cautious: long duration is not automatically equilibrium; equilibrium-like claims require stable/cyclic-stable trajectories plus run-length and analysis-window sensitivity, while initialization/environment alternatives can be retained as separate dimensions. Multiple stable regimes are reported rather than pooled into one equilibrium mean.

No new defect was demonstrated in these initialization/burn-in interpretation contracts beyond existing #320 and the known post-#326 resource dependency.

## Continuation-state audit

The historical #168 repair is substantially present. `SimulationCheckpoint` now carries a separate `continuationDigest64` over experiment configuration, time and stop boundary, world identity, population, M9 temporary mobility, full resource and migration checkpoint state, all named RNG positions, retained event/metric histories, state digest and resume lineage. `Simulation::from_checkpoint` validates that identity before execution, reconstructs the world, validates population/resources/M9/founder state, restores RNG positions and finally rechecks present-state digest.

The ordinary persistence regression compares an uninterrupted eight-year run to a run checkpointed at year 3 and resumed, requiring identical manifest and checkpoint after removing only declared resume-lineage provenance. This is strong positive evidence for ordinary annual-boundary continuation.

### Adversarial initial-boundary probe

Temporary PR #331 added one additional exact-equivalence test for the public `checkpoint_at_year(0)` boundary:

1. run a two-year experiment uninterrupted;
2. construct the same experiment, checkpoint immediately at year 0, restore with `Simulation::from_checkpoint`, and run to year 2;
3. first require equal terminal `stateDigest64`;
4. compare the complete metric-snapshot day sequence;
5. compare the complete terminal checkpoint after removing only resume lineage.

The probe branch passed formatting and Clippy. The workspace-test step then failed.

Source inspection isolates the cause. `MetricSeries::annual()` starts empty. `checkpoint_at_year(0)` advances zero time and nevertheless calls `ensure_terminal_metric_snapshot()`, inserting a day-0 derived metric snapshot. Resume preserves that history. The equivalent uninterrupted run does not create a day-0 snapshot and begins its annual observations at day 365. For a two-year run the resulting observation-day sequences are therefore:

- uninterrupted: `[365, 730]`;
- checkpoint/resume from year 0: `[0, 365, 730]`.

The terminal scientific present state can remain equal, but requesting a checkpoint at the valid initial boundary changes retained authoritative output history.

## #332 repair/reverification — checkpoint serialization is not observation

The repair distinguishes **serialization boundaries** from **scientific observation boundaries**. A non-terminal checkpoint requested at simulation day 0 no longer calls terminal-metric recording merely in order to serialize state. Its metric series is therefore empty, exactly as it is in a newly constructed uninterrupted simulation. True terminal runs at duration zero still receive a day-0 terminal metric, and non-zero annual checkpoints retain the annual boundary snapshot already produced by model advancement.

The same change is applied to both ordinary `Simulation` and transformed `SpatialLandscapeSimulation` checkpoint paths. Resume validation additionally fails closed on legacy/nonconforming **non-terminal day-zero checkpoints that already contain metric snapshots**, even if their continuation integrity is resealed; the implementation does not silently delete an observation and thereby rewrite provenance.

Independent arithmetic reproduces the original two-year discrepancy without importing AnthroSim: uninterrupted `[365, 730]` versus legacy year-zero-resumed `[0, 365, 730]`, a 3-vs-2 (**+50%**) retained-observation difference. The repaired path is `[365, 730]`; a year-one checkpoint remains `[365]`; and a genuinely terminal zero-duration run remains `[0]`.

Regression coverage requires complete final checkpoint/run equality after removing only declared resume-lineage provenance for both ordinary and transformed spatial execution. Existing non-zero checkpoint regressions remain in place, and the long-run diagnostics test suite is rerun because downstream studies consume completed-run metric histories.

An empty valid day-zero metric history is **not** exempt from metric-series identity checks. Invariant validation now checks metric schema version and cadence before allowing the special empty-history case, and a dedicated regression corrupts the schema on a valid year-zero checkpoint and requires `validate_invariants()` to fail. This closes the self-review edge where accepting zero snapshots could otherwise have weakened corruption detection.

No `MODEL_SEMANTICS_ID` or metric schema bump is required: causal simulation dynamics and completed-run metric cadence are unchanged, and schema v3 already declares `annual_boundary_plus_terminal`. This repair makes year-zero checkpoint behavior conform to that existing contract rather than introducing new executable model semantics.
