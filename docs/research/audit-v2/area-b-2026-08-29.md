## Adversarial experiments

### 1. Declared-founder genealogy plausibility

PR #319 added a controlled founder definition containing two living female founders:

- parent: `birth_day = -101`;
- child: `birth_day = -100`;
- the child declares the first founder as `femaleParent`.

The declared parent is therefore one day old at the child's birth. Current `validate_parent(...)` checks only that a declared parent exists, has the expected reproductive sex and was born strictly before the child. It does not impose a parent-at-child-birth age plausibility constraint.

The adversarial test verified that `Simulation::new(...)` accepts this definition. This demonstrates AV2-003 / issue #320.

### 2. PersonId relabelling and sequential demographic RNG consumption

PR #319 also constructed two scientifically isomorphic two-person founder populations with the same residence, conditions, reproductive sex and ages but with the 20-year-old and 40-year-old records assigned opposite canonical PersonIds. Fertility and non-demographic mortality were disabled; age-specific background mortality was set to 0.2 below age 30 and 0.8 at age 30+.

Across seeds `1..=2000`, the test demonstrated that at least one paired seed had a different final survivor count after the consistent PersonId reassignment.

This is **not classified as a new marginal-demography defect**. Sequential named RNG streams assign exchangeable variates according to evaluation order; a fixed seed therefore does not provide agent-level common-random-number identity after records or states are rearranged. AnthroSim already preserves this limitation explicitly in the paired-seed/RNG contract tracked by historical issue #214, and the current suite includes `rng::tests::conditional_consumption_breaks_agent_level_paired_seed_alignment`.

The result matters for counterfactual interpretation: a same-seed relabelled or treatment comparison is not “the same individual shocks with only the treatment changed.” It does not by itself show that the marginal mortality law or ensemble expectation depends on PersonId.

## Findings

### AV2-003 — declared founder genealogy accepts biologically impossible parent-child age gaps

Severity: **P2**

Issue: #320

A research-facing declared founder population can pass core validation with a parent only one day older than a declared child. Founder genealogy is authoritative state used by kin and downstream analysis, so an impossible relationship should fail closed or be governed by an explicit founder-age plausibility contract.

This requires malformed declared input and does not corrupt valid model-generated births, so it is P2 rather than a P0/P1 executable demographic failure.

## Remaining uncertainty / boundary

Area B did not attempt empirical calibration of mortality, fertility, age structure or parent-age distributions. Passing synthetic controls and executable invariants does not establish historical realism.

Detailed household topology, kin semantics beyond the founder-genealogy validity boundary, household fission/formation and cross-system demographic-household effects remain for Area C and later integration passes.

The PersonId probe should be revisited only if AnthroSim adopts an agent/event-keyed stochastic mode or begins claiming agent-level common-random-number counterfactuals. Ordinary ensemble inference should instead be tested under Areas H/I.

## Repeat conditions

Repeat the Area B adversarial checks if any of the following change:

- founder genealogy or reproductive-history validation;
- parentage eligibility/locality;
- newborn initialization;
- demographic RNG assignment/coupling semantics;
- population record ordering in ways claimed to preserve stronger same-seed counterfactual identity.
