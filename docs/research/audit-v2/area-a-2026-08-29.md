## Executable scheduler contract observed

Both `Simulation` and `SpatialLandscapeSimulation` implement the same fixed-boundary order within each model year:

1. process M9 temporary boundaries strictly before the next fixed M3/M4 day;
2. on that day, if M3 is due, settle the elapsed resource interval and resolve condition-mediated plus M2 background mortality;
3. process M9 transitions/starts due on that exact day;
4. if M4 is due, execute the permanent-migration decision boundary;
5. after all subannual fixed boundaries, execute the annual M2 fertility/parentage finalizer;
6. if configured, apply household lifecycle after the demographic finalizer and before the annual metric snapshot.

The v15+ mortality path does not redraw M2 background mortality in the annual finalizer. M2 background risk is selected using interval-start age, converted to elapsed exact-rational interval risk, and resolved jointly with condition-mediated mortality at M3 boundaries. The competing-risk implementation uses independent cause streams and a symmetric dual-trigger attribution rule rather than call-order cause priority.

Same-day M4 relocation is deliberately after mortality. The demographic finalizer reconstructs pre-M4 persistent residence from same-day migration events for parentage exposure while newborn residence follows the mother's already-updated persistent household residence.

M9's `next_boundary_day` admits a due boundary on the current day, so day-zero triggers are not skipped when the first later fixed boundary is searched. Its within-day lifecycle priority is explicit: return completion, arrival, return departure, then new outward departure.

## Anti-bias / neighboring-system review

- Scheduler priority can be causal, but the principal M3 -> M9 -> M4 priority is explicitly documented and implemented identically by both hosts rather than emerging from container order.
- Mortality cause attribution was specifically checked for former scheduler-priority bias; the current competing-risk resolver removes that first-called cause priority.
- Boundary double-count/skip risk was attacked exhaustively across all allowed fixed-clock pairs and not demonstrated.
- M9 same-day and day-zero boundary behavior was inspected to check for boundary omission.
- Annual parentage uses pre-same-day-M4 residence by explicit reconstruction rather than zero-duration destination exposure.
- Household lifecycle is sequenced after annual fertility and was noted as a neighboring structural mechanism; its internal scientific assumptions belong to Area C.
- Sequential named RNG streams consume variates conditionally and can therefore create entity-level paired-seed/order questions. The repository already acknowledges conditional-consumption alignment in `rng.rs`; whether scientifically irrelevant entity-ID permutations can alter materially interpreted demographic outcomes remains an explicit hypothesis for Areas B/H rather than being silently declared safe here.
