## Repaired/working spatial contracts confirmed

The audit did not contradict the following current mechanisms:

- landscape schema v2 explicitly binds row-major `CellId` to a north-up area grid, with exact integer cell extents and doubled-integer centres;
- active M4/M9 movement rejects rectangular cells, preventing one cardinal grid step from silently representing unequal physical X/Y distances;
- M4 candidate search is bounded to a Manhattan-radius local neighborhood and excludes the origin because staying is represented by its own comparator;
- all households at one M4 boundary evaluate one common pre-move snapshot and relocations are applied simultaneously;
- candidate stochastic weights are exactly proportional to positive utility improvement above the stay/minimum-improvement threshold;
- M9 edge cost is symmetric, integer and depends on both adjacent endpoint movement costs;
- M9 multi-source routing explicitly represents unreachable origins when traversability disconnects them from the focal region;
- current M9 routing preserves every exactly equal minimum focal destination rather than discarding all but the first;
- current M9 destination ties are resolved without consuming mutable sequential RNG state, using the keyed policy `m9/equal-cost-destination-keyed-v1`;
- persistent residence remains separate from temporary physical-presence state; transit deliberately has no invented cell-level location;
- the finite world is an explicit closed graph, and unresolved/analyst-crop boundaries require extent sensitivity rather than being silently interpreted as historical barriers;
- existing boundary tests demonstrate both M4 candidate clipping in undersized domains and M9 reachability changes when a route is artificially cut off by the finite edge, then convergence after sufficient buffer is added.

### M4 candidate geometry

For every candidate radius `r = 1..32`, the checker confirmed the exact interior candidate-count formula:

`2r(r + 1)`

and found **0 reflected candidate-set failures**. Thus an interior flat neighborhood has the same unlabeled candidate geometry under X reflection.

Representative finite-edge clipping counts were:

| Radius | Interior candidates | Corner candidates |
|---:|---:|---:|
| 1 | 4 | 2 |
| 2 | 12 | 5 |
| 3 | 24 | 9 |
| 4 | 40 | 14 |
| 8 | 144 | 44 |
| 16 | 544 | 152 |
| 32 | 2112 | 560 |

This clipping is large at wide radii, but it is not hidden: `spatial_boundary.rs` explicitly classifies the simulation edge as a closed finite graph, and the existing extent-convergence tests diagnose truncated M4 horizons and require sensitivity for analyst-defined crops/unresolved extents. No new defect is assigned to the clipping itself.

### Stable candidate order under reflection

The same candidate **set** is symmetric, but the stable iteration order is not reflection-equivariant. For representative radii the number of same-index positions that differ after X reflection is:

| Radius | Order mismatches |
|---:|---:|
| 1 | 2 / 4 |
| 2 | 8 / 12 |
| 3 | 18 / 24 |
| 4 | 32 / 40 |
| 8 | 128 / 144 |
| 16 | 512 / 544 |
| 32 | 2048 / 2112 |

This does **not** demonstrate a marginal M4 spatial bias by itself: candidate uncertainty and choice use sequential stochastic streams, and a mirrored treatment with the same master seed is not guaranteed to attach the same variates to reflected candidate identities. Historical #214 already defines that paired-seed limitation for state/candidate-dependent sequential consumption. Area E therefore records this as additional coupling evidence for Area H rather than opening a duplicate defect.

A future strong mirror-counterfactual claim would need keyed candidate-level shocks or an analysis design that does not assume agent/candidate-level common random numbers.

### M9 equal-minimum keyed selection

For the symmetric flat 3x1 two-destination case, the checker reproduced the exact current keyed policy across tie seeds `1..=100000` with fixed origin 2, household 1 and trigger 0:

- equal-minimum candidate 0: `49,886` selections;
- equal-minimum candidate 1: `50,114` selections;
- shares: 49.886% and 50.114%.

This is consistent with the repaired executable intent: no permanent lower-CellId winner remains. It is qualitatively incompatible with the active M9.4 contract text, which still says the smaller authoritative `CellId` wins every exact tie.

## Finding

### AV2-006 — active M9.4 contract still documents superseded lower-CellId equal-cost selection

Severity: **P2**

Issue: #327

Historical #190 correctly identified deterministic lower-CellId destination choice as a scientifically consequential spatial preference. Current code has since repaired that behavior by preserving all equal minima and resolving each household/trigger through the keyed tie policy.

`docs/research/m9-temporary-travel-semantics-v1.md`, however, still presents the old smaller-CellId winner as current semantics. Destination identity affects visitor location, visitor resource demand and downstream aggregation/resource observables, so this documentation drift can materially misstate the causal mechanism used by a current run.

This is a documentation/interpretation defect, not a newly discovered executable routing defect. #190 remains a completed historical repair; #327 tracks synchronization of the current-facing contract with v19 behavior.

## Cross-system notes carried forward

- **Households × movement:** #324 can create cohort/newborn-sorted household units that subsequently act as M4/M9 units. That is the Area C finding and must be tested after repair in the mandatory integration pass rather than double-counted here.
- **Movement × resources:** #326 can alter condition and therefore M4 pressure; temporary visitors also alter destination demand seen by M4. Dedicated cross-system verification should occur after #326 is repaired.
